## 🧠 What the humans do

| Human job | What it means |
|---|---|
| Choose | Pick between options |
| Review | Look at art, gameplay, plans |
| Approve | Say “yes, continue” |
| Steer | Say “change this” |
| Reject | Say “no, not this” |

---

## 🤖 What the agents do

| Agent job | What it means |
|---|---|
| Plan | Break work into small tasks |
| Build | Implement code and content |
| Show | Present results clearly |
| Revise | Improve based on feedback |
| Document | Record what changed |
